## Quick Start & Local Preview

### Option A: Direct Browser Preview
Double-click `index.html` or open it in any web browser (Chrome, Edge, Firefox, Safari). No build tools, internet connection, or server required!

### Option B: Local Web Server
```bash
# Using Node
npm start

# Or using Python (if installed)
python -m http.server 3000
```
Open `http://localhost:3000` in your browser.

## Free 1-Minute Deployment Options

- **GitHub Pages:** Push this folder to a GitHub repository, go to `Settings` > `Pages`, choose `main` branch, and save.
- **Vercel:** Run `npx vercel` in this folder or connect your GitHub repository on vercel.com.
- **Netlify:** Drag and drop this folder directly into netlify.com/drop.
